# Liger — subdivision-limit to CAD exterior

`Liger_Body_CAD.arc` is the current exterior CAD conversion. It contains only the
three authored exterior parts: the main shell, front cowl, and roof/glass frame.
The interior, wheels, lamps, and production panel decomposition are excluded.

## Conversion method

The rebuild follows the robust **unpacked SubD-to-NURBS** method used by CAD
converters when larger face packs cannot be made watertight:

1. read each face of the original Blender Catmull–Clark control cage;
2. evaluate its level-2 subdivision-limit samples;
3. solve a tensor-product cubic interpolation system;
4. create a native SolidArc bicubic NURBS face;
5. use coincident samples for every shared face boundary;
6. reflect the authored half exactly about `Y=0`; and
7. sew each exterior part and side into oriented B-rep sheets.

This retains the original topology around the wheel arches, vents, nose, cockpit,
and extraordinary vertices. The openings visible in the proof are authored body
openings; the random black gaps introduced by the experimental packed conversion
have been withdrawn.

## Geometry and accuracy

The document contains 4,528 native bicubic CAD faces in six exterior B-rep sheets.
This is deliberately the stable unpacked representation: regular regions could be
merged only if their common boundary curves and derivatives remain exactly shared.
The attempted independent large-surface fitting did not satisfy that requirement.

Residuals measured at held-out subdivision samples:

| Part | Native faces | RMS error | Maximum error |
|---|---:|---:|---:|
| Main shell | 4,366 | 0.054 mm | 2.142 mm |
| Front cowl | 76 | 0.362 mm | 3.988 mm |
| Roof/glass frame | 86 | 0.014 mm | 0.190 mm |

The largest deviations are confined to exceptional non-quad cage faces.

The images under `SolidArc/Liger_CAD_*.png` display the actual CAD surface and

The lines are not an overlaid Blender wireframe. They are rendered from the native
NURBS/B-rep document. `SolidArc/render_cad.arc` replays with zero refusals.

## Regeneration

```bash
bash Vehicles/tools/setup_bpy.sh
LD_LIBRARY_PATH="$HOME/.bpystubs" "$HOME/.bpyenv/bin/python" \
  Vehicles/tools/subd_to_solidarc.py \
  Vehicles/Liger/Source/Liger_named.blend \
  Vehicles/Liger/Liger_Body_CAD.arc

bash Vehicles/tools/setup_env.sh
"$HOME/.solidarc/build/SolidArc" --proofs Vehicles/Liger/SolidArc \
  Vehicles/Liger/SolidArc/render_cad.arc
```
