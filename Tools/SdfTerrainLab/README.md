# SLATE · SDF Terrain Lab

Node-based volumetric terrain studio: build land from SDF primitives and
generators (Gaea-style graph), then erode it **live** with settling-guaranteed
particles — rain, rivers, wind, thermal talus, rockfall — over true 3D geometry
with real caves, arches and overhangs. No heightmaps. Water follows the currents
the rivers carve.

## Run (no build step)

```sh
cd Tools/SdfTerrainLab
python3 -m http.server 8000
# open http://localhost:8000
```

Any static server works (`npx serve`, `vite preview`, …). ES modules require
`http://` — `file://` will show a boot hint instead. Needs a WebGL2 browser.
`three.js` is vendored (`vendor/`), so there are no CDN/runtime dependencies.

## Workflow

1. **Graph** (bottom dock, `Tab` to add): chain primitives → generators →
   combine/modify → **Terrain Output**. Baking is automatic on release.
2. **Sim nodes**: add Rain / River / Wind / Thermal / Rockfall / Lake. They run
   live on the baked SDF — press `Space` and watch particles cut, carry and dump
   sediment. River paths edit in-viewport (✎ Edit path → click terrain).
3. **Inspect**: shading modes (Full/Clay/Wire/**Flux**/Wet/Sed/Mat), mass ledger
   in the Erosion tab, diagnostics panel (top-right `WebGL2 ✓`).
4. **Export**: PLY/OBJ mesh, heightmap PNG, **flowmap PNG** (RG dir / B flux for
   engine water shaders), graph JSON, screenshots.

Presets: **Canyon rivers**, **Sea cliffs + caves**, **Wind dunes**, Empty plot.

## Tests

```sh
node --test tests/*.test.js
```

Covers SDF primitives + field compiler, graph topology/serialization, erosion
mass conservation + **settle guarantee** + bounded cutting under an abusive
emitter + thermal balance + dry wind, and mesher outward-normals/empties.

## Method notes

- Volume: dense SDF + material + sediment + wetness + flux + flow (`draft` /
  `standard` / `high`). Sign: inside < 0.
- Droplets: capacity `C ∝ speed × water × slope`, contact-only exchange with a
  normalized compact brush (~1 voxel), evaporation, and **five terminating
  paths** (settle/evaporate/age/lake/exit) — see `docs/research.md`.
- Water: river ribbons draped on the live carved bed + lake discs; shader
  advects normals/foam along per-vertex current with depth absorption and
  shoreline/rapids foam.

Method references: Hans Theobald Beyer-style droplet erosion; Mei–Decaudin–Hu 2007 (GPU
hydraulic erosion); Hartley et al. 2024 "Flexible terrain erosion" (SDF/voxel
particle alteration + settling). Full citations in `docs/research.md`.
