# Map code provenance

`src/map/road/`, `src/map/render/textures.js`, `src/map/render/materials.js`, `src/map/render/propsLib.js`
and `src/game/view/camera.js` are copied from the `Experimental/RoadEditor` directory of
`SultanAladin/Frontier-`, branch `arena/80ae15cf-frontier` (commit 0c82acb).

The upstream repository has no LICENSE file, and its NOTICE.md states that no licence grant is made.
Permission from the repository owner is needed before this code is redistributed.
