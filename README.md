# D-DAY: Breakwater Run

A standalone low-poly browser driving survival game built with Three.js.

## Run locally

Serve the repository directory and open the reported URL:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

## Controls

- **W / S** — accelerate / reverse
- **A / D** — steer
- **Shift** — boost
- **Space** — handbrake
- **R** — restart the run

The objective is to drive the winding beach route to the breach in the giant sea wall before the rising water, minefields, bunker machine guns, and aircraft bomb runs stop the vehicle.
