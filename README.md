# Slate

Slate's current deliverable is the browser-side **IlluminationHost** vehicle/HMI prototype, reconstructed under [`Experimental/IlluminationHost`](Experimental/IlluminationHost/README.md). It is a pre-native-C++ experiment built with JavaScript and WebGPU/WGSL; its custom vehicle and rigid-body solvers do not use Jolt Physics.

See [`Experimental/README.md`](Experimental/README.md) for how to run it and [`Experimental/IlluminationHost/ROADMAP.md`](Experimental/IlluminationHost/ROADMAP.md) for the next planned vehicle-effects and steering work.
