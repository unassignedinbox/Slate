# Slate

## Road Editor → [`road-editor/`](road-editor/)

Spline road authoring for the Frontier Terrain Lab engine, dressed in the
Exhibits UI system: plan + 3D editing, junctions, terrain drape, validation,
drive-through preview, and engine-convention exports (`.road.json`, `.obj`,
`.csv`, `.png`).

```sh
cd road-editor && npm install && npm run dev   # → http://localhost:5174
```

See [`road-editor/README.md`](road-editor/README.md) for features, shortcuts,
formats, and the engine integration snippet.
