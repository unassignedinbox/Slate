# Slate

## RoadEditor/

A standalone, self-contained **road editor** for the Frontier engine
(`streamlinkinbox/Frontier`, Terrain Lab): draw a road centerline over
procedural or imported terrain, build a real ribbon mesh (asphalt, shoulders,
lane markings, curve banking), and export it as OBJ or a reloadable
`frontier-road` JSON project. The UI follows the Frontier Terrain Lab interface
and its design exhibits. No build step — open `RoadEditor/index.html` or serve
the folder statically. See `RoadEditor/README.md`.
