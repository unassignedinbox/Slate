# Native panel visual proof

These PNG files were captured from the C++ `SceneDirectorPanel` at 1180 × 760 using its real
`RecordingSurface`/Dear ImGui draw commands and the default Dear ImGui font atlas. The capture is an offscreen
software rasterisation of the native draw list; it does not execute or screenshot the HTML reference.

- `scene-director-native.png` — Outliner and Properties presentation.
- `texture-paint-native.png` — Layer Stack and Layer Inspector presentation.

The interactive Windows executable that records the same panel is `PanelValidationHost`.
